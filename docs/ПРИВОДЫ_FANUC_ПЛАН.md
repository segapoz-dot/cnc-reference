# Раздел «Приводы FANUC»: договорённость и план

21 ноября 2026. Записано по разговору с владельцем приложения для продолжения работы в Claude Code и Codex.

## Что нужно пользователю

В справочнике нужен отдельный вход «Приводы» → «FANUC». Для каждого типа привода нужна фотография передней панели, чтобы узнать блок на станке, а затем поиск по коду на его индикаторе. Частые ситуации: разряд батареи абсолютного датчика и неисправность вентилятора.

## Как устроить раздел

1. Сначала выбрать семейство и **тип блока**: питание/рекуперация (PSM), сервопривод осей (SVM), привод шпинделя (SPM). Затем сверить точный номер изделия с шильдиком (обычно A06B-...). Не объединять все блоки FANUC в одну таблицу кодов.
2. Карточка семейства показывает фото лицевой стороны, название, диапазон номеров изделий, место индикатора и ссылку на руководство. Карточка конкретной модели добавляется только при проверенном соответствии фотографии и номера изделия.
3. Поиск принимает код с дисплея привода **и** аварийный код ЧПУ. Результат явно показывает, откуда считан код, к какому блоку и семейству относится расшифровка. Одно и то же число может иметь разный смысл у SVM, SPM, PSM и у разных серий.
4. Для каждой аварии хранить: исходный текст руководства, проверенный русский перевод, возможные причины, безопасные первичные проверки, номер и редакцию руководства, страницу. Если модель не определена, показывать несколько возможных совпадений с запросом уточнить шильдик.
5. Батарея абсолютного датчика может находиться в отдельном батарейном блоке или в сервоприводе; сигнал о её разряде не следует приписывать каждому SVM. Вентилятор также различается по блоку и серии. Добавить отдельные карточки симптомов «Батарея» и «Вентилятор», ведущие к подходящим кодам и процедурам из руководства.
6. Для фотографий использовать собственные снимки с разрешения владельца либо изображения с разрешённым повторным использованием. Для каждой фотографии записывать источник, автора/правообладателя и модель. Не подменять фото одной серии похожим блоком другой серии.

## Минимальные данные для каждой записи

`family`, `module_type`, `part_numbers`, `display_type`, `alarm_code`, `alarm_source` (дисплей/ЧПУ), `title_ru`, `message_en`, `cause_ru`, `checks_ru`, `manual_id`, `manual_revision`, `page`, `photo_path`, `photo_credit`.

## Порядок наполнения

Начать с распространённых семейств αi и βi, разделив PSM/SVM/SPM. Сверить коды, названия блоков и процедуры по руководствам конкретных серий. Добавлять последующие серии и модели только вместе с источниками и проверенными фото. В интерфейсе не обещать «все приводы FANUC», пока охват ограничен.

## Источники для проверки

- [FANUC America: CNC Tech Tips](https://www.fanucamerica.com/support/cnc/tech-tips) — отдельные материалы по авариям сервоприводов и шпиндельных приводов, батареям и вентиляторам.
- [FANUC αi Maintenance Manual, B-65285EN/04](https://www.industrialmco.com/wp-content/uploads/2023/03/FANUC-AC-SERVO-MOTOR-Alphai-series-AC-SPINDLE-MOTOR-Alphai-series-SERVO-AMPLIFIER-Alphai-series.pdf) — семейство αi, состав модулей, батареи абсолютных датчиков, вентиляторы и диагностика.
- [FANUC βi-B/βi Maintenance Manual](https://www.industrialmco.com/wp-content/uploads/2023/03/FANUC-AC-SERVO-MOTOR-Betai-B-Betai-series-AC-SPINDLE-MOTOR-Betai-series-SERVO-AMPLIFIER-Betai-B-series.pdf) — отдельное руководство для βi, не смешивать его таблицы с αi.

Руководства в последних двух ссылках размещены сторонним архивом; перед публикацией конкретной расшифровки сверить номер документа и редакцию с изделием.
