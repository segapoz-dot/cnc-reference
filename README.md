# Справочник ЧПУ

План нового раздела для продолжения работы: [Приводы FANUC](docs/ПРИВОДЫ_FANUC_ПЛАН.md).

Веб-приложение с поиском по коду, префиксу FANUC, тексту и серии стойки. Значок — шпиндель над раскрытой книгой.

Каталоги содержат краткие русские пояснения и указатели на страницы заводских руководств. Указатели требуют открытия PDF. Полнота русской расшифровки пока ограничена. G-команды относятся к указанному в каждой записи языку и версии.

Для локального запуска выполните `python3 -m http.server 8783` в этой папке и откройте http://localhost:8783.

Для GitHub Pages выберите ветку main и корень репозитория в Settings → Pages. После успешной первой загрузки приложение сохраняет интерфейс и JSON-каталоги для работы без сети. Ссылки на руководства требуют доступа к PDF.

При изменении файлов увеличьте версию кеша в sw.js.
